# 订阅额度与 API 零售价：低价供给的成本边界

核实时间：北京时间 2026-11-26 20:36–21:10。只使用公开页面、公开接口和上一轮已保存的盘口快照。没有购买账户、没有转售、没有付费探测。

本文件不改写 `REPORT.md` 里已经核实的卖家边界。订阅机制只解释「这一类上游产品能不能在经济上打出这种价格」，不把任何 Surplus offer id 归到某个匿名卖家。

InferHub 约 37,012 个活跃供给实例、其中 Mistral Vibe 约 25,195、Qwencloud/Alibaba 约 8,105，是供给实例计数。同一订阅可以挂出多个实例，所以这两个数字不是独立用户、付费订阅数或流量份额。本轮公开接口 `https://inferhub.dev/api/stats` 与 `/api/providers` 返回的是页面 HTML，没有按家族拆开的 JSON。同日早些时候定价页写的是 Active providers 37,315。37,012 与 37,315 是同一量级的实例总数，家族拆分沿用本轮给出的计数，没有在本机重新点算。

## 五问的答案

1. 官方订阅的成本结构，能够解释一部分 90% 以上的折价，但不能解释全部挂牌价。能解释的部分，是「额度已经买下、边际成本接近零」的闲置出售，以及「额度按缓存命中价扣、买方仍按未缓存折扣价付费」的价差。专为转售而新买的订阅，在冷输入和输出上盖不住 95% 折扣。
2. 可以用已确认机制解释的，是 Venice DIEM 的约 10%–65% 折扣（Gondola 公开成交），以及在高缓存、输入为主的流量上，百炼 Token Plan / QwenCloud Token Plan 相对按量刊例的约 80%–92% 折扣。Mistral Vibe 只有在较大的欧元额度真实存在、并且第三方调用能打到这笔额度时，才可能解释 DeepSeek V4.1 Flash 1017 的缓存型低价。
3. 仍然无法用专买转售解释的，是 InferHub 上 GLM 5.3 的 $0.0014 / $0.0044 地板（相对官方 $1.4 / $4.4 为 99.9%），以及在冷输入或输出占比高时，DeepSeek 1017 相对百炼忙时刊例、相对 Mistral 未缓存刊例的 95% 以上折扣。Claude Code 的 token 额度未公布，Opus 5.5 的 97.3% 折价没有可计算的保本利用率。
4. 三家上游都有订阅续费。三家公开条款都没有把个人版、消费版额度授权为可转售的商业容量。续费存在，合法的商业转售授权没有看到。
5. 卖家把当月额度卖完再补货，等于进入「专买转售」。补货之后，只有高缓存、输入为主、并且额度按官方刊例的缓存价扣减的流量，才在 Token Plan Pro 和（条件性的）Mistral 大额预算上留下利润。GLM 5.3 的地板价、冷输入、以及输出很重的请求，补货后不盈利。

## 4. 同一笔请求的缓存情景

上一轮 20 笔成交没有缓存读取、缓存写入、冷输入的拆分。下面不用冷输入牌价覆盖全部输入 token。卖方所得按盘口有效价计算，买方扣费就是这个价。上游成本按同一 token 数的刊例情景计算。

代表形状取自上一轮成交，不是新的采样：

- 输入为主：每 100 万输入配 3,570 输出（59,393 输入 / 212 输出这一档）。
- 输出很重：每 100 万输入配 492,000 输出（3,048 输入 / 1,500 输出这一档）。

### 百炼按量刊例相对 Surplus DashScope 报价

Surplus 该通道主流量档 `cost_multiplier` 0.0478，有效价输入 $0.007177 / 百万、输出 $0.033495 / 百万（相对 OpenRouter $0.15 / $0.70）。输入为主时，每百万输入的买方扣费是 $0.00730。

| 情景 | 按量刊例 | Token Plan Pro 分摊（月费占刊例 15.6%） | 买方扣费 | 刊例 / 扣费 | 分摊 / 扣费 |
|---|---|---|---|---|---|
| 忙时，输入全部未缓存 | $0.302 | $0.0472 | $0.00730 | 41.4× | 6.5× |
| 闲时，输入全部未缓存 | $0.151 | $0.0236 | $0.00730 | 20.7× | 3.2× |
| 忙时，输入 90% 为缓存命中 | $0.0394 | $0.00615 | $0.00730 | 5.4× | 0.84× |
| 忙时，输入全部为缓存命中 | $0.0102 | $0.00159 | $0.00730 | 1.40× | 0.22× |
| 闲时，输入全部为缓存命中 | $0.00511 | $0.00080 | $0.00730 | 0.70× | 0.11× |

忙时全缓存刊例：`(1e6 × 0.04 + 3570 × 8) / 1e6 = ¥0.0686`，合 $0.0102。买方扣费 $0.00730 仍低于这份刊例。闲时全缓存刊例 ¥0.0343 合 $0.00511，买方扣费高于刊例。按量刊例低于报价，只出现在闲时且输入几乎全是缓存命中的情景。缓存写入价未知，没有单列。$0.0472 是订阅分摊，不是刊例。

### Token Plan Pro，专买转售

假设 Credits 按被消耗的刊例行计，100 Credits = ¥1，月费占刊例价值 15.6%。下表是「每百万输入」的订阅分摊成本与买方扣费 $0.00730 的差。正数表示这一流量形状在该利用率下能覆盖月费。

保本利用率 = 月费 / 全额用完时的销售收入。超过 100% 表示把整月 Credits 都用在这种流量上仍然亏。

| 流量 | 全额售出收入 | 保本利用率 | 50% 利润 | 80% 利润 | 100% 利润 |
|---|---|---|---|---|---|
| 忙时冷输入，输入为主 | $7.19 | 646% | −$42.90 | −$40.75 | −$39.31 |
| 忙时缓存 90%，输入为主 | $55.16 | 84.3% | −$18.92 | −$2.37 | $8.66 |
| 闲时缓存 90%，输入为主 | $110.32 | 42.2% | $8.66 | $41.76 | $63.82 |
| 闲时缓存 90% 再乘夜间 5 折 | $220.64 | 21.1% | $63.82 | $130.01 | $174.14 |
| 忙时全缓存，输出很重 | $11.90 | 391% | −$40.55 | −$36.98 | −$34.60 |

夜间 5 折是否可以叠在闲时刊例上，帮助中心没有写。这一行是情景，不是已确认规则。输出很重指每百万输入配 492,000 输出；全缓存也覆盖不了按 ¥8/百万计的输出。

美元利润按月费 ¥312 / 6.7096 = $46.50 计算。已经买下的订阅：月费是沉没成本，边际成本在额度用尽前接近零，任何正的售价都是增量收入，机会成本是本人没用掉的交互额度，没有公开的美元报价。

InferHub `alicn` 地板 $0.0174 / $0.0696 高于 Surplus 的 $0.007177 / $0.0335。同一套 Token Plan 数学下，输入为主、缓存 90% 的保本利用率更低，利润更厚。`alitp` 地板 $0.045 / $0.18 更接近「月费占刊例 15.6%」之后的冷输入成本（忙时输入订阅分摊约 $0.0465 / 百万），像是按未缓存成本报价，而不是按缓存成本报价。

| C 促销 €280.50 | Surplus 0.070 | $9.84 | 152% | $265.36 | 5.7% |

缓存 100% 时，Surplus 0.070 的 $0.0105 高于 Mistral 缓存价 $0.007，额度扣得慢、售价相对高，所以情景 B/C 在「全部输入都是缓存命中、而且大额 Vibe 预算真能被第三方打到」时，50% 利用率已经盈利。90% 缓存、情景 B、Surplus 0.070：保本利用率 40.6%；50% 利用率利润 $3.46，80% 为 $14.52，100% 为 $21.90（1 欧元按 1 美元）。数字在 `mistral_budget_scenarios.csv`。

InferHub 地板 $0.0051 低于缓存刊例 $0.007。情景 B 把月费摊到额度上之后，缓存输入的单位成本约为 0.107 × $0.007 = $0.00075。把伴随的输出也算进同一笔请求后，输入为主、100% 缓存的全额收入是 $64.29，保本利用率 23.3%，50% 利用率利润 $17.16。闲置额度解释得了这个地板；情景 B 且流量几乎全是缓存命中时，专买转售也解释得了。冷输入解释不了。

GLM 5.3 的 InferHub 地板 $0.0014 / $0.0044 是官方 $1.4 / $4.4 的 0.1%。即便输入全部按缓存价 $0.14 扣，每 1 美元额度只能卖出 $0.01。情景 B 全额缓存收入约 $1.40，低于 $14.99。专买转售没有保本点。闲置额度的边际成本为零，可以解释有人挂出这个价格，解释不了补货之后继续盈利。

## 7. 补货之后还剩什么

- 百炼 Token Plan：个人版自动续费存在，但不能退订。续费后的经济账是专买转售。输入为主、缓存命中率大约 90%、再赶上闲时或夜间 5 折时，Pro 有利润。冷输入、或者输出 token 占比接近上一轮「3,048 进 / 1,500 出」那种形状，续费后亏损。个人版条款禁止生产自动化和多人共用，所以这条利润依赖违规使用，不是可签约的商业容量。
- Mistral：情景 B 或 C 且流量几乎全是 DeepSeek 缓存命中时，续费后有利润。只拿到 API 那 €12.75 时，续费后没有利润。GLM 5.3 地板价在三种欧元情景下续费都没有利润。消费者条款和商业条款都禁止转售 key。账户可以被停，下月额度不是一项稳定的批发合同。
- Claude Code：续费本身合法，用续费后的凭证给第三方转发不在授权范围内。因为没有 token 上限，无法判断续费后按 $0.108 / $0.54 卖出是否覆盖 $20、$100 或 $200。
- Gondola / DIEM：补货就是继续质押。近 30 日公开结果显示卖家拿到面值的 65.7%，折扣远浅于 Surplus 上的 Mistral 和百炼盘。它解释的是 Venice 额度的日内折价，解释不了 90%–97% 的订阅型挂牌。
