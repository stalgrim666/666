## 1. 产品与额度

官方现在能确认的结构：每个计划有两笔分开的月度金额额度，Vibe & Studio 一笔，API 一笔。额度按 Mistral 刊例金额扣，不是按固定 token。第三方编程工具和 harness 只打 API 那一笔。用尽后，开了按量预付就扣预付 credits，否则停到下一期。按量不是另一个套餐，也不把订阅额度并进普通 API 余额。Free 模式的文档写明不含 API；创建 API key 需要开通计费和按量。见 [Subscriptions](https://docs.mistral.ai/admin/billing-usage/subscriptions)、[Usage and limits](https://docs.mistral.ai/admin/billing-usage/usage-limits)。

缓存：通用说明写缓存 token 按标准输入价的 10% 计，见 [Prompt caching](https://docs.mistral.ai/inference/conversations/advanced/prompt-caching)。定价表对具体模型另有数字，以表为准。DeepSeek V4.1 Flash 1017 的缓存读取是 $0.007，等于输入价的 2.3%，不是 10%。GLM 5.3 是 $1.40 / 缓存 $0.14 / 输出 $4.40，缓存正好 10%。GLM 5.3 Flash 是 $0.15 / 缓存 $0.03 / 输出 $0.50，缓存是 20%。三行都在 2026-11-26 的定价表上，所以这三款模型可以走 API 刊例。它们是否同时走 Vibe 那一笔大额，官方定价页没有写。

## 5. 同一笔请求的成本

形状沿用上一轮成交里的输入为主：每 100 万输入配 3,570 输出。缓存写入没有官方单价，不单列。买方扣费按报价乘全部输入 token，因为二级市场的挂牌价没有缓存分项。这是买方支付，不是把冷输入牌价套到缓存 token 上的收入。

DeepSeek 1017，每 100 万输入：

| 缓存占输入的比例 | Mistral 按量成本 | 0.1344 档收入 | 差额 | 0.070 档收入 | InferHub 地板 $0.0039 收入 |
|---|---|---|---|---|---|
| 0% | $0.304 | $0.0205 | −$0.284 | $0.0107 | $0.0040 |
| 89.8%（Surplus 模型级，含其他上游） | $0.0412 | $0.0205 | −$0.0207 | $0.0107 | $0.0040 |
| 96.7%（InferHub mv/ 多轮命中） | $0.0210 | $0.0205 | −$0.0005 | $0.0107 | $0.0040 |
| 100% | $0.0113 | $0.0205 | +$0.0092 | $0.0107 | $0.0040 |

按量采购下，0.1344 档要到输入几乎全部是缓存命中才打平，96.7% 时还亏 $0.0005。0.070 档和 $0.0039 地板在 100% 缓存时仍然低于按量成本，因为地板 $0.0039 低于缓存刊例 $0.007。这两档不能靠缓存本身赚钱，必须有比刊例更便宜的额度，或者在亏着卖。

若仍按定价页曾经印过的 $25.50 API 额度、月费 $14.99 来摊（14.99/25.50 = 刊例的 58.8%），96.7% 缓存时 0.1344 档的成本是 $0.0123，收入 $0.0205，每百万输入毛利 $0.0082。把整笔 $25.50 都用在这个形状上，收入约 $24.94，减去月费后约 $10。这是**条件计算**：额度金额已经从定价页移除，而且第三方工具按规定只能打 API 那一笔，打不到帖子里的 €255 Vibe 额度。

免费月的月费是 0。如果这个月仍然带上那笔 API 额度，卖出即收入。官方 11 月 23 日的帖子没有写额度金额。不能把免费月写成已经证实的货源。

Medium 3.5 的地板 $0.0015：即便缓存仍按 10 月 30 日的 $0.15，卖价也只有缓存刊例的 1%。$25.50 的额度若按 $1.50 的输入价扣完，按这个地板卖出只收回 $0.026。它解释不了「靠价差赚钱」。它解释得了「额度边际成本接近零时，用一个默认的 0.1% 倍率把实例挂出去」。

GLM 5.3 健康最低输入 $0.166 高于 Mistral 缓存刊例 $0.14。缓存命中的输入腿，按量采购也能高于卖价。输出 $0.599 对刊例 $4.40 仍然差得很远。输入为主、缓存很高时，这一档可以靠缓存打平；输出一多就不行。InferHub 的 GLM 5.3 地板 $0.0056 低于缓存刊例 $0.14，按量采购解释不了。

## 7. 盈利和补货

公开材料里没有一张卖家账单，也没有一个人写明自己在用 Mistral 额度给 InferHub 或 Surplus 供货。Reddit 上能找到的是订阅者描述自己的后台额度。X 检索上一轮已因额度用尽失败，本轮没有再取到原文，11 月 23 日的帖子用的是媒体引文。

按数字能说的话：

- 按量刊例解释得了「缓存极高、而且卖价不低于缓存价」的输入腿。DeepSeek 的 0.1344 档在 100% 缓存时每百万输入赚 $0.009；在 InferHub 实测的 96.7% 时亏 $0.0005。0.070 档和 $0.0039 地板即使用满缓存也低于按量成本。
- 曾经印在定价页上的 $25.50 API 额度，如果现在的账户里还有，能把 0.1344 档在 96.7% 缓存下做成大约 $10 的月毛利（月费 $14.99）。定价页从 11 月 24 日起不再印这个数，所以这是条件，不是已确认的现行货源。
- 免费月的月费是 0，任何正的售价在额度用尽前都是增量。帖子没有写额度。11 月 23 日当天订单簿几乎没有新增 id。不能把 11 月 25 日 22 时那 122 条 0.1344 算成领了 MISTRALVIBE 的人。
- Medium 3.5 的 4,122 个 0.1% 档，按任何已公布的额度金额去卖，单账户收入是几美分到几角。它像默认倍率的闲置挂牌，不像一套算得过来的批发。
- 补货：再付 $14.99 买一个月，只有在 API 额度仍接近 $25.50、流量缓存率接近 97%、而且卖在 0.1344 而不是地板价时，DeepSeek 才有薄利。地板价补货后不盈利。条款不允许把 key 转售，账户可以被停。没有看到一份可续的批发合同。

## 结论

Mistral 的低价不是一种机制。

已经证实的是：官方按量价里，DeepSeek 的缓存读取只有 $0.007；Surplus 主流量档卖 $0.020，健康最低档卖 $0.0105；InferHub 的 Mistral Vibe 地板已经到 $0.0039。缓存解释得了主流量档在缓存率极高时接近打平，解释不了两个地板价。订阅侧证实的是两笔金额额度、第三方只打 API 额度、以及定价页曾经印过 $25.50 又在 11 月 24 日拿掉。欧洲免费月证实的是 11 月 17 日限量三个月、11 月 23 日改为不限量一个月，帖子里没有赠金数字。没有看到低于刊例的特殊采购价；LLM Gateway 接的就是刊例。

仍然只是推断的是：匿名报价用了免费码、用了那笔已下架的 $25.50、或者打到了 €255 的 Vibe 额度。2.5 万个 InferHub 实例里，绝大多数是弃用模型 Medium 3.5 的挂牌，不是 DeepSeek 的供货规模。公开记录里没有一份把这些实例和某次促销对上的账单。
